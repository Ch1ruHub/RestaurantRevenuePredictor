# Restaurant Monthly Revenue Predictor

This submission predicts `Monthly_Revenue` (INR) from restaurant operating characteristics. `Outlet_ID` is excluded because it is an identifier rather than a meaningful predictor.

## What is included

- `restaurant.csv` - the supplied 2,500-row dataset.
- `model_training.py` - reproducible data-quality checks, linear-regression diagnostics, training, evaluation, and model saving.
- `restaurant_pipeline.py` - portable preprocessing-plus-regression class used by both training and the app.
- `model_training.ipynb` - notebook version of the same workflow.
- `model.pkl` - saved preprocessing plus linear-regression pipeline, generated by the training script.
- `app.py` - Streamlit application that loads `model.pkl`; it never retrains at start-up.
- `figures/` and CSV/JSON reports - residual, Q-Q, Cook's-distance, linearity, VIF, coefficient, quality, and metric outputs.

## Assumption decisions

The script checks missing values, duplicates, reasonable business ranges, categorical values, linearity examples, VIF, Durbin-Watson, standardized residuals, leverage/Cook's distance, and residual plots. It caps the five customer ratings above the valid 1-5 scale at 5.0 and records this in `data_corrections.json`. It removes the identifier from prediction features, one-hot encodes nominal categories, standardizes numeric features, and retains valid influential rows while reporting them rather than silently deleting observations.

## Run

```powershell
python -m pip install -r requirements.txt
python model_training.py
streamlit run app.py
```

Open the local URL displayed by Streamlit. Enter valid operating inputs, then select **Predict monthly revenue**. The displayed result is a monthly INR estimate for manager scenario planning.
